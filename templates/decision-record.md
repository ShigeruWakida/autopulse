検討の区切りで、次の書式の「決定記録」を Markdown で出してください。
確定した事項・新しい作業・未決の事項を混ぜないこと。推測や提案を「決定」に書かないこと。会話の全文は不要です。
該当がない節は「- なし」とだけ書きます。Issue 番号が分かる決定には必ず書きます。
「新しくやること」には、既存の Issue に無い作業だけを書きます。既存 Issue の作業の進め方や条件が変わったときは「決定」に書き、その Issue 番号を付けます。

```markdown
# 決定記録 {{REPO_NAME}} YYYY-MM-DD

## 決定
### （決定の見出し）
- Issue: #番号（なければ「なし」）
- 内容: 決めたこと（1〜3文）
- 理由: なぜそう決めたか
- 日付: YYYY-MM-DD

## 新しくやること
### （作業のタイトル）
- 優先度: P0 / P1 / P2 / P3
- 分類: Spec / Hardware / PCB / Firmware / Software / Test / Docs / Other
- 概要: 何をするか
- 完了条件:
  - [ ] チェックできる条件
  - [ ] 2つ目の条件（必要なだけ）
- 検証: どう確かめるか
- 次の一手: 次に取りかかれる具体的な一文

## 未決
### （論点）
- 状態: 今の候補と、決めるのに必要なこと
```
